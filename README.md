## 📌 Overview

**Tech Indro** is India's leading AI-powered educational platform designed to take learners from **zero to one** in modern tech skills — Artificial Intelligence, Robotics, and Software Development. Built for everyone (IT, Non-IT, all age groups) with **no laptop or tech background required**.

---

## ✨ Key Features

- 🤖 **24/7 Conversational AI Mentor**: Voice-to-voice interaction (mic speech input & spoken answers) with clean Gemini-style code formatting.
- 💻 **IndroLabs Code Playground**: Interactive in-browser compiler for Python, JavaScript, and HTML/CSS.
- 🏆 **TSOC (Tech Season of Code)**: Hands-on fellowship and real-world project mentorship.
- 📝 **Adaptive Test Series**: Real-time quizzes with instant scoring and explanations.
- 📊 **Unified Portals**: Dedicated Student Dashboard, Parent Panel, and Admin Analytics.

---

## 💻 Tech Stack

- **Frontend**: HTML5, Modern CSS3, Vanilla ES6+ JavaScript, Lucide Icons
- **Backend API**: Node.js, Express.js (`server.js`)
- **Voice Engine**: Web Speech API (SpeechRecognition & SpeechSynthesis)
- **Data Store**: Lightweight JSON flat-file datastores

---

## 🚀 Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/techindro/tech-indro-website.git
cd tech-indro-website

# 2. Install dependencies
npm install

# 3. Start local server
npm start
```
Then open `http://localhost:5000` in your browser.
